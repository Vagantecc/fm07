# Football Manager 2007 — Android (Winlator)

Configuração otimizada para rodar o **Football Manager 2007** no Android via **Winlator**.

## Arquivos

| Arquivo | Descrição |
|---------|-----------|
| `GUIA_INSTALACAO.md` | Guia completo passo a passo |
| `fm2007-winlator-container.json` | Configuração pronta do container Winlator |
| `install.sh` | Script auxiliar para preparar os arquivos no PC |

## Início Rápido

```bash
# No PC: extrair e preparar os arquivos
chmod +x install.sh
./install.sh Football_Manager_2007_Europe.zip
```

Depois, siga o **[Guia de Instalação](GUIA_INSTALACAO.md)**.

## Compatibilidade

- Android 8.0+, ARM64
- RAM mínima: 3 GB livre
- Funciona bem em celulares intermediários (Snapdragon 720G+)
